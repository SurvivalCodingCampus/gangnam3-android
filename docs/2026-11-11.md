# Jetpack Compose UI 및 상태 관리

## 용어 및 개념 정리
- State hoisting (상태 끌어올리기): 컴포저블을 stateless로 만들어 재사용성과 테스트 용이성을 높이는 패턴
- Recomposition (재구성): 상태 변화에 따라 컴포저블 트리를 다시 그리는 과정

## 핵심 코드
```kotlin
@Composable
fun RecipeCard(title: String, modifier: Modifier = Modifier) {
    Card(modifier = modifier) {
        Text(text = title)
    }
}
```

## 오류 해결 및 인사이트
- 오류: 상태가 갱신되어도 UI가 리컴포지션되지 않는 현상
- 원인: `mutableStateOf`가 아닌 일반 변수를 상태로 사용함
- 해결: `remember { mutableStateOf(...) }`로 래핑하여 구독 가능하도록 수정
