### 1.  안드로이드 콤보스(Compose)
옛날에는 앱 화면을 만들 때 일일이 손으로 위치를 잡고 고쳐야 해서 실수가 많았어요. 
하지만 Compose(컴포즈)라는 최신 마법 기술을 쓰면, 마치 레고 블록을 조립하듯 쉽고 예쁘게 스마트폰 화면을 만들 수 있답니다.

1. 레고 블록처럼 화면 쌓기 (배치 도구)화면에 글자나 그림을 어떻게 놓을지 결정하는 블록들이에요.
    - Column (세로 쌓기): 블록을 위에서 아래로 차곡차곡 쌓는 기계예요. (예: 줄글이나 목록)
    - Row (가로 쌓기): 블록을 왼쪽에서 오른쪽으로 나란히 놓는 기계예요.
    - Box (상자 겹치기): 블록을 그림자처럼 겹쳐서 놓을 수 있는 마법 상자예요.
   
2. 옷을 입히고 꾸미기 (Modifier - 수정자)글자나 상자에 색칠을 하거나 여백을 주는 꾸미기 도구예요.
   - .background(color = Color.Red): 배경을 빨간색으로 칠해줘요.
   - .padding(16.dp): 테두리 안쪽에 여유 공간(숨 쉴 공간)을 만들어줘요.
   - .fillMaxWidth(): 화면의 가로 폭을 꽉 채우도록 늘려줘요.
   
3. 꼭 지켜야 할 3가지 황금 규칙 (중요!)좋은 앱을 만들기 위해 개발자들이 약속한 규칙이에요.
   - 상태를 품지 않기 (Stateless): 화면에 보여줄 데이터는 남이 건네주는 대로 보여주기만 해요.
   - 함수 안에서 마음대로 바꾸지 않기: 화면을 그려주는 함수 안에서는 스마트폰의 중요한 상태를 직접 바꾸지 않아요.
   - 일러바치기 (콜백 이용하기): 버튼을 누르는 등의 일이 생기면, "저 버튼 눌렸어요!" 하고 외부(어른/부모 함수)에 신호(콜백)를 
     보내서 처리하게 해요.

         3. 연습문제 3: Custom Tabs요구사항: labels, selectedIndex 파라미터, onValueChange: (Int) -> Unit (클릭된 탭 인덱스 반환) 콜백 사용   Kotlinimport androidx.compose.foundation.layout.Row
            import androidx.compose.foundation.layout.fillMaxWidth
            import androidx.compose.material3.ButtonDefaults
            import androidx.compose.material3.ElevatedButton
            import androidx.compose.material3.Text
            import androidx.compose.runtime.Composable
            import androidx.compose.ui.Modifier
            import androidx.compose.ui.graphics.Color

            @Composable
            fun CustomTabs(
               labels: List<String>,
               selectedIndex: Int,
               onValueChange: (Int) -> Unit,
               modifier: Modifier = Modifier
             ) {
               Row(modifier = modifier.fillMaxWidth()) {
                  labels.forEachIndexed { index, label ->
                     val isSelected = (index == selectedIndex)

                     ElevatedButton(
                         onClick = { onValueChange(index) },
                         modifier = Modifier.weight(1f),
                         colors = ButtonDefaults.elevatedButtonColors(
                             containerColor = if (isSelected) Color(0xFF129575) else Color.White,
                             contentColor = if (isSelected) Color.White else Color.Gray
                         )
                     ) {
                         Text(text = label)
                     }
                 }
               }
            }

### 2. 안드로이드 상태(State)를 가지는 Composable 작성규칙
앱을 만들다 보면 버튼을 누를 때마다 숫자가 올라가거나(카테고리, 좋아요 등), 하트 모양이 빨간색으로 색칠되는 등의 변화가 필요합니다.
이처럼 화면이 어떻게 생겨야 하는지 결정하는 "기억하고 있어야 할 변화의 값"을 프로그래밍에서는 상태(State)라고 부릅니다.   

1. 앱에게 기억력을 선물하는 방법 (remember와 rememberSaveable)
 . 그냥 일반 변수: 앱은 기억력이 아주 나빠서 화면이 새로 그려지면(재구성) 방금 일어난 일을 싹 다 잊어버려요.   
  -  remember (기억해 줘!): "내가 방금 몇 번 클릭했는지 기억해 둬!" 하고 앱에게 수첩을 쥐여주는 마법이에요.   
  -  rememberSaveable (스마트폰을 돌려도 기억해 줘!): 스마트폰을 가로로 휙 돌리거나 화면을 회전시키면 앱이 깜빡하고 
     리셋될 수 있는데, 이 마법을 쓰면 화면이 돌아가거나 언어가 바뀌어도 꿋꿋하게 기억을 유지해 준답니다!   
2. 상태를 위로 끌어올리기! (상태 호이스팅 - State Hoisting)
  - 비유하자면: 자녀(작은 부품)가 혼자서 고민하고 결정하기보다는, 부모님(상위 화면/Preview)에게 "저 이거 바꿔주세요!" 하고 상태를 
    위로 쏙 올려서(호이스팅) 부모님이 관리하게 만드는 착한 규칙이에요.   
  - 왜 이렇게 할까요?: 부품이 너무 복잡해지지 않고, 다른 곳에서도 이 부품을 똑같이 재사용하기 아주 좋아지기 때문입니다!   
3. 사진과 아이콘 꾸미기Image(...): 스마트폰 안에 있는 예쁜 그림(Drawable)을 화면에 띄워요.   
  - ContentScale.Crop: 사진을 찌그러트리지 않고 비율을 지키면서 액자에 꽉 차게 예쁘게 채워 넣어요.   
    - Icon(...): 별 모양, 하트 모양 같은 작은 아이콘을 띄우고, tint 속성으로 색깔을 자유롭게 바꿉니다.
