### 1.  안드로이드 MVVM패턴.
    -  햄버거 가게에 비유한 "MVVM 패턴"이란?
       앱을 만들 때 모든 코드를 한 곳에 뭉쳐 놓으면 나중에 고칠 때 엄청 헷갈려요. 
       그래서 역할을 View(손님용 카운터), ViewModel(매니저님), Repository & DataSource(주방과 식재료 창고)로 깔끔하게 나누는 
       정리 정돈 규칙이 바로 MVVM 패턴입니다!
    1. 초등학생 눈높이로 이해하는 MVVM 역할 놀이
      1) View (예쁜 카운터 & 메뉴판)
        - 우리가 스마트폰 화면에서 직접 보고 터치하는 곳이에요.   
        - 카운터 직원은 복잡한 요리법이나 창고 재고를 몰라도 돼요. 그냥 "매니저님이 주신 메뉴판을 예쁘게 보여주고, 손님이 버튼을 누르면 
          매니저님께 알려드리는 역할"만 해요.   
      2) ViewModel (똑똑한 매장 매니저님)
        - 화면(View)과 창고(Repository) 사이에서 일하는 두뇌이자 중재자예요.   
        - 손님이 "치즈버거 검색해 주세요!" 하면 창고에서 재료를 가져오게 시키고, 화면이 보여주기 딱 좋게 정리해서 전달해 줘요.   
        스마트폰 화면을 빙글 돌려도 매니저님은 자리를 지키고 있어서, 화면이 바뀌어도 데이터가 사라지지 않게 지켜준답니다!   
      3) Repository & DataSource (식재료 창고 & 창고지기)
        - 인터넷 서버, 데이터베이스, 파일 등에서 진짜 데이터(레시피 목록, 사진 등)를 가져오는 곳이에요.   
        - 내일 카운터 인테리어나 메뉴판 디자인이 싹 바뀌어도, 식재료 창고(Repository)는 건드릴 필요가 없도록 독립적으로 만들어 둡니다.   
      4) LazyColumn (똑똑한 진열대) & Coil (사진 배달부)
        - LazyColumn: 긴 목록을 보여줄 때, 화면에 지금 보이는 몇 개만 쏙쏙 그려서 스마트폰 배터리를 아껴주는 똑똑한 세로 진열대예요.   
        - Coil: 인터넷 주소(URL)에 있는 음식 사진을 빠르고 가볍게 불러와 화면에 띄워주는 사진 배달부예요

### 2. 오늘의 핵심 명령어 모음.
    ViewModel()                    화면용 데이터를 보관하고 관리하는 클래스          화면을 지켜주는 듬직한 매니저님   
    MutableStateFlow / StateFlow   상태 변화를 자동으로 알려주는 데이터 통           값이 바뀌면 화면에 "새로 그려줘!" 하고 소문 내는 통   
    viewModelScope.launchViewModel 안에서 백그라운드 작업 실행                     매니저님이 바쁜 일을 시킬 때 쓰는 전용 작업실 (화면 닫히면 자동 정리)   
    collectAsState() /             Flow데이터를 Compose 화면 상태로 변환           매니저님이 주는 실시간 데이터를 화면이 알아듣게 바꾸는 통역기
    collectAsStateWithLifecycle()    
    LazyColumn + items(key = ...)  화면에 보이는 항목만 효율적으로 스크롤 목록 표시   보이는 것만 그리는 똑똑한 세로 스크롤 목록   
    AsyncImage(...)                인터넷 이미지 URL을 비동기로 불러와 표시          인터넷에서 사진을 가져와 보여주는 이미지 상자   
    by lazy                        실제로 필요할 때 처음 한 번만 객체 생성           쓸 일이 생길 때까지 아껴뒀다가 처음 쓸 때만 만드는 마법   
    MainDispatcherRule + runTest   화면(Main) 스레드 없이도 ViewModel 단위         진짜 폰을 켜지 않고도 컴퓨터 안에서 매니저님 
                                   테스트 실행                                    일 처리를 미리 시험해 보는 도구

   package com.example.gangnam3.presentation.saved_recipes

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.example.gangnam3.data.model.Recipe
import com.example.gangnam3.data.repository.RecipeRepository
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch

data class SavedRecipesUiState(
val isLoading: Boolean = false,
val recipes: List<Recipe> = emptyList(),
val errorMessage: String? = null
)

class SavedRecipesViewModel(
private val recipeRepository: RecipeRepository
) : ViewModel() {

    private val _uiState = MutableStateFlow(SavedRecipesUiState())
    val uiState: StateFlow<SavedRecipesUiState> = _uiState.asStateFlow()

    init {
        // ViewModel 생성 시 init 블록에서 데이터 로드
        loadSavedRecipes()
    }

    fun loadSavedRecipes() {
        viewModelScope.launch {
            _uiState.update { it.copy(isLoading = true, errorMessage = null) }
            try {
                val savedList = recipeRepository.getSavedRecipes()
                _uiState.update {
                    it.copy(
                        isLoading = false,
                        recipes = savedList
                    )
                }
            } catch (e: Exception) {
                _uiState.update {
                    it.copy(
                        isLoading = false,
                        errorMessage = e.message ?: "저장된 레시피를 불러오지 못했습니다."
                    )
                }
            }
        }
    }

    fun onToggleBookmark(recipeId: Int) {
        _uiState.update { state ->
            val updated = state.recipes.map { recipe ->
                if (recipe.id == recipeId) {
                    recipe.copy(isBookmarked = !recipe.isBookmarked)
                } else {
                    recipe
                }
            }
            state.copy(recipes = updated)
        }
    }
}

@Composable
fun SavedRecipesRoute(
viewModel: SavedRecipesViewModel,
modifier: Modifier = Modifier
) {
val uiState by viewModel.uiState.collectAsStateWithLifecycle()

        uiState = uiState,

@Composable
fun SavedRecipesScreen(
uiState: SavedRecipesUiState,
onBookmarkClick: (Int) -> Unit,
modifier: Modifier = Modifier
) {
Column(
modifier = modifier
.fillMaxSize()
.background(Color.White)
.statusBarsPadding()
) {
// 상단 타이틀 ("Saved recipes")
Box(
modifier = Modifier
.fillMaxWidth()
.padding(top = 16.dp, bottom = 12.dp),
contentAlignment = Alignment.Center
) {
Text(
text = "Saved recipes",
fontSize = 18.sp,
fontWeight = FontWeight.SemiBold,
color = Color(0xFF121212)
)
}

        when {
            uiState.isLoading -> {
                Box(
                    modifier = Modifier.fillMaxSize(),
                    contentAlignment = Alignment.Center
                ) {
                    CircularProgressIndicator(color = PrimaryGreen)
                }
            }

            uiState.errorMessage != null -> {
                Box(
                    modifier = Modifier
                        .fillMaxSize()
                        .padding(24.dp),
                    contentAlignment = Alignment.Center
                ) {
                    Text(
                        text = uiState.errorMessage,
                        color = Color.Red,
                        fontSize = 14.sp
                    )
                }
            }

            else -> {
                LazyColumn(
                    modifier = Modifier.fillMaxSize(),
                    contentPadding = PaddingValues(horizontal = 20.dp, vertical = 12.dp),
                    verticalArrangement = Arrangement.spacedBy(20.dp)
                ) {
                    items(
                        items = uiState.recipes,
                        key = { it.id }
                    ) { recipe ->
                        SavedRecipeCard(
                            recipe = recipe,
                            onBookmarkClick = { onBookmarkClick(recipe.id) }
                        )
                    }
                }
            }
        }
    }
}

@OptIn(ExperimentalCoroutinesApi::class)
class MainDispatcherRule(
val testDispatcher: TestDispatcher = UnconfinedTestDispatcher()
) : TestWatcher() {

    override fun starting(description: Description) {
        Dispatchers.setMain(testDispatcher)
    }

    override fun finished(description: Description) {
        Dispatchers.resetMain()
    }

package com.example.gangnam3.presentation.saved_recipes

import com.example.gangnam3.data.model.Recipe
import com.example.gangnam3.data.repository.RecipeRepository
import com.example.gangnam3.utils.MainDispatcherRule
import kotlinx.coroutines.ExperimentalCoroutinesApi
import kotlinx.coroutines.test.runTest
import org.junit.Assert.assertEquals
import org.junit.Assert.assertFalse
import org.junit.Rule
import org.junit.Test

@OptIn(ExperimentalCoroutinesApi::class)
class SavedRecipesViewModelTest {

    @get:Rule
    val mainDispatcherRule = MainDispatcherRule()

    private class FakeRecipeRepository : RecipeRepository {
        override suspend fun getSavedRecipes(): List<Recipe> {
            return listOf(
                Recipe(
                    id = 1,
                    title = "Traditional spare ribs baked",
                    chefName = "Chef John",
                    cookingTime = "20 min",
                    rating = 4.0,
                    imageUrl = "",
                    isBookmarked = true
                ),
                Recipe(
                    id = 2,
                    title = "spice roasted chicken with flavored rice",
                    chefName = "Mark Kelvin",
                    cookingTime = "20 min",
                    rating = 4.0,
                    imageUrl = "",
                    isBookmarked = true
                )
            )
        }
    }

    @Test
    fun `ViewModel 생성 시 init 블록에서 저장된 레시피 목록이 StateFlow에 로드된다`() = runTest {
        val fakeRepository = FakeRecipeRepository()
        val viewModel = SavedRecipesViewModel(recipeRepository = fakeRepository)

        val state = viewModel.uiState.value
        assertFalse(state.isLoading)
        assertEquals(2, state.recipes.size)
        assertEquals("Traditional spare ribs baked", state.recipes[0].title)
    }

    @Test
    fun `북마크 토글 호출 시 해당 레시피의 북마크 상태가 반전된다`() = runTest {
        val fakeRepository = FakeRecipeRepository()
        val viewModel = SavedRecipesViewModel(recipeRepository = fakeRepository)

        viewModel.onToggleBookmark(recipeId = 1)

        val toggledRecipe = viewModel.uiState.value.recipes.first { it.id == 1 }
        assertFalse(toggledRecipe.isBookmarked)
    }
}
