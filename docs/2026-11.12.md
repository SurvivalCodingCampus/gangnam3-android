### 1.  안드로이드 앱 UI 만들기

앱 화면을 만들 때 일일이 컴퓨터한테 "여기에 글자 넣고, 저기에 버튼 붙여!" 하고 
복잡하게 명령해야 했어요. 그러다 보니 실수도 잦고 머리가 아팠죠.   
하지만 안드로이드 젯팩 컴포즈(Compose) 라는 신기한 도구가 나온 뒤로는 아주 쉬워졌답니다! 
핵심 규칙 3가지만 기억하면 돼요.
1.  그림은 척척, 마음대로 바꾸지 않기 (Stateless)   
 -  화면에 글자나 그림을 보여줄 때는 "이거 보여줘!" 하고 데이터만  전달해주어야 해요. 
    화면 스스로 맘대로 기억하고 바꾸려고 하면 혼란이 생겨요.   
2.  화면 안에서 직접 대장 노릇 하지 않기   
 -  화면을 그려주는 함수 안에서는 "화면 이동해!" 라거나 "데이터를 바꿔버려!" 같은 중요한 
    결정을 직접 하면 안 돼요. 구경만 해야 합니다.   
3.  일이 생기면 어른(외부)에게 귓속말하기 (Callback)
 -  버튼을 꾹 눌렀거나 글자를 적었을 때 일어나는 변화는 "나 이거 눌렸어요!" 하고 
    콜백(알림장)을 통해 바깥 세상(앱 로직)에 알려주어야 해요.

### 🛠️ 꼭 알아야 할 핵심 앱 화면을 만들 때 꼭 쓰는 마법의 주문(명령어)들을 정리
1. 화면에 글자나 모양을 띄울 때
 -  @Composable: "나 지금 화면에 보이는 부품(함수)을 만들고 있어요!"라고 컴퓨터에게 알려주는 표시예요.   
 -  Text(text = "Hello"): 화면에 글자를 뿅 하고 띄워주는 명령어예요.
2. 상자처럼 나란히 정렬할 때 (배치 도구)
 -  Column: 레고 블록을 위에서 아래로 (세로로) 차곡차곡 쌓아 올릴 때 써요.   
 -  Row: 블록을 왼쪽에서 오른쪽으로 (가로로) 나란히 진열할 때 써요.   
 -  Box: 물건을 겹쳐 놓듯이 위아래로 겹쳐서 배치할 때 써요.
3. 꾸미기 대장 (Modifier)
 -  Modifier.background(Color.Red): 배경 색상을 빨간색으로 칠해줘요.   
 -  Modifier.padding(16.dp): 테두리 안쪽에 여유 공간(숨 쉴 공간)을 줘요.   
 -  Modifier.fillMaxWidth(): 화면 가로 폭을 꽉 채워요.
4. 미리 보기와 테스트
 -   @Preview(showBackground = true): 앱을 직접 스마트폰에 넣지 않고도, 컴퓨터 화면 
     미리보기로 어떻게 생겼나 미리 확인해요.   
 -   composeTestRule.onNodeWithText("텍스트"): 테스트할 때 화면에 특정 글자가 잘 
     나오는지 찾아주는 스마트한 감시병이에요.

#### 문제1.
enum class ButtonSize {
BIG, MEDIUM, SMALL
}

import androidx.compose.foundation.layout.*
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.material3.*
import androidx.compose.runtime.Composable
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.unit.dp
import androidx.compose.ui.unit.sp

@Composable
fun RecipeButton(
text: String,
size: ButtonSize,
onClick: () -> Unit,
modifier: Modifier = Modifier
) {
// 크기별 높이, 패딩, 글자 크기 설정
val (height, horizontalPadding, fontSize, showArrow) = when (size) {
ButtonSize.BIG -> Quad(56.dp, 24.dp, 16.sp, true)
ButtonSize.MEDIUM -> Quad(48.dp, 20.dp, 14.sp, true)
ButtonSize.SMALL -> Quad(36.dp, 16.dp, 12.sp, false)
}

    Button(
        onClick = onClick,
        modifier = modifier
            .height(height)
            .fillMaxWidth(), // 혹은 필요에 따라 wrapContentWidth()
        shape = RoundedCornerShape(12.dp),
        colors = ButtonDefaults.buttonColors(
            containerColor = Color(0xFF0F9D58) // 이미지 속 초록색톤 예시
        )
    ) {
        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.Center,
            verticalAlignment = Alignment.CenterVertically
        ) {
            Text(
                text = text,
                color = Color.White,
                fontSize = fontSize
            )
            if (showArrow) {
                Spacer(modifier = Modifier.width(8.dp))
                Text(
                    text = "→",
                    color = Color.White,
                    fontSize = fontSize
                )
            }
        }
    }
}

// 4개의 값을 한 번에 리턴하기 위한 보조 데이터 클래스 또는 Destructuring용
private data class Quad<A, B, C, D>(val first: A, val second: B, val third: C, val fourth: D)
