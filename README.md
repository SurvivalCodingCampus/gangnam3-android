# RecipeApp

안드로이드 수업 과제 제출용 저장소입니다.

## 과제 제출 방식

### 1. 본인 브랜치 확인

학생별 브랜치는 다음 형식으로 사용합니다.

```text
student/01_김경환
```

PR의 대상 브랜치(`base`)는 반드시 본인의 브랜치로 지정합니다.

```text
student/01_김경환
```

> **주의:** `master` 브랜치로 PR을 보내지 않습니다.

### 2. 과제 구현

수업에서 안내한 과제를 본인 브랜치에서 구현합니다.

### 3. 테스트 및 빌드 확인

과제 구현 후 테스트 코드를 실행하고 결과를 확인합니다.

```bash
./gradlew test
```

실행 화면 스크린샷 또는 테스트 실행 결과를 캡처하여 PR 본문에 첨부합니다.

### 4. Pull Request 작성

PR 제목은 다음 형식을 사용합니다.

```text
[YYYY-MM-DD] 이름 - 과제 제출
```

예시:
```text
[2026-11-11] 김경환 - 과제 제출
```

PR 본문에는 다음 내용을 작성합니다:
- 과제 구현 내용
- 앱 실행 화면 캡처 또는 테스트 결과 스크린샷
- AI 활용 및 인사이트
- 회고

PR 작성 시 확인할 내용:
- [ ] PR 대상 브랜치가 `master`가 아닌 본인 브랜치인가?
- [ ] PR 제목 형식을 준수했는가?
- [ ] 스크린샷을 첨부했는가?
- [ ] 회고 및 AI 인사이트를 작성했는가?
